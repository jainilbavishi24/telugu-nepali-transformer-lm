## Setup

1. Install necessary python dependencies by
   ```
   pip install -r requirements.txt
   ```
2. you are good to go, since most files directly download models/dataset from HF there is not much setup required.
3. However if you want to fine-tune models your self, you have to run `generate_dataset.py` before running `finetune_reasoning.py`
4. All the plots are perfectly reproducible by the scripts present in {language}/eval folder(s)
